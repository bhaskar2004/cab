# Cab Booking Service

A modern, professional cab booking platform built with Next.js for Gauribidanur's premier transportation service.

## Features

- **Instant Fare Calculator**: Transparent pricing at ₹12/km
- **WhatsApp Booking**: Direct booking integration
- **24/7 Availability**: Round-the-clock service
- **Multiple Vehicle Types**: 5-seater sedans and 7-seater SUV/MPV options
- **Responsive Design**: Works seamlessly on all devices

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **UI Components**: Radix UI
- **Icons**: Lucide React

## Project Structure

- `/app` - Next.js app directory with pages and layouts
- `/components` - Reusable React components
- `/public` - Static assets

## Deployment

This Next.js app can be deployed to any platform that supports Node.js applications.

Check out the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying) for more details.
